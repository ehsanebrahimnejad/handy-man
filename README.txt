GITHUB PAGES:
1. Upload every file and the assets folder to the same GitHub repository.
2. Keep index.html in the root of the repository.
3. Open Settings > Pages.
4. Choose Deploy from a branch.
5. Select main and /root.
6. Save.

IMPORTANT:
Do not rename or move the files inside the assets folder unless you also update their paths in index.html.
