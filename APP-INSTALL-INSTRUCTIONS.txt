ERS APP FOR IPHONE AND ANDROID

WHAT THIS IS
This is an installable Progressive Web App (PWA). It works on both iPhone and Android and opens like a regular app.

UPLOAD TO GITHUB
1. Unzip ERS_APP_IPHONE_ANDROID.zip.
2. Upload every file and the icons folder to the root of your GitHub repository.
3. Replace the existing index.html.
4. Commit changes.
5. Wait 2–3 minutes.
6. Refresh ershomefix.com.

ANDROID INSTALL
1. Open ershomefix.com in Chrome.
2. Tap the Install ERS App button, or tap Chrome menu > Add to Home screen.
3. Tap Install.

IPHONE INSTALL
1. Open ershomefix.com in Safari.
2. Tap the Share button.
3. Scroll down and tap Add to Home Screen.
4. Tap Add.

IMPORTANT
- iPhone Safari does not show the automatic install button. Use Share > Add to Home Screen.
- Keep manifest.json, service-worker.js and the icons folder.
- Your website must use HTTPS. GitHub Pages and ershomefix.com already support HTTPS.
- This is installable on both platforms without App Store or Google Play approval.
